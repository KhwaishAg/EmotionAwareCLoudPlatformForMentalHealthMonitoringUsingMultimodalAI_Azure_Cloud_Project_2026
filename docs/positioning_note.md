## Project positioning

This system is a student well-being screening / early-support tool. It is
not a medical diagnostic system, and no output from any modality — including
the fused multimodal assessment — constitutes a clinical diagnosis.

All data is provided voluntarily by the student with consent; this is a
self-report and opt-in screening flow, not covert monitoring. A student may
skip any optional modality (voice, and any future modality) and the system
continues to function on the modalities actually provided.
