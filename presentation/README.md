# Presentations & Milestone Materials

## Emotion Aware Cloud Platform For Mental Health Monitoring Using Multimodal AI

This directory stores presentation slide decks, milestone review materials, visual architecture diagrams, and demonstration assets for the **Multimodal Student Stress/Risk Assessment and Early-Intervention Support System**.

---

## Directory Purpose

The `presentation/` directory serves as the repository for:
- **Academic Project Presentations:** Initial proposal, interim progress presentations, and final viva/defense decks.
- **Milestone Reviews:** Scheduled checkpoint presentations for faculty advisors and academic committees.
- **System Architecture Diagrams:** High-resolution exports of the three-modality pipeline, fusion mechanism, and data flow.
- **Demonstration Materials:** Screenshots, demo walk-through storyboards, and evaluation presentation summaries.

---

## Supported File Formats

To ensure compatibility, version tracking, and accessibility across team members and reviewers, the following formats are permitted:

| Format | File Extension | Intended Use Case |
|---|---|---|
| **Portable Document Format** | `.pdf` | Final, distributable slide decks and frozen milestone presentations |
| **Microsoft PowerPoint** | `.pptx` | Working presentation decks and editable collaborative templates |
| **Markdown Slide Decks** | `.md` | Marp / Slidev text-based slide source files |
| **Vector & Raster Images** | `.png`, `.svg` | High-resolution architectural diagrams, UI mockups, and charts |

---

## File Naming Conventions

To maintain order across academic review stages, all files deposited in this directory must adhere to the following convention:

```
[Phase]_[Topic]_[YYYYMMDD].[ext]
```

### Standard Prefixes:
- `Proposal_` — Initial project proposal and problem formulation decks
- `Milestone1_` — Review 1: Architecture, dataset specifications, and feature pipelines
- `Milestone2_` — Review 2: Individual modality models (Questionnaire, Voice, Behavioral baselines)
- `Milestone3_` — Review 3: Multimodal fusion, consistency analysis, and explainability
- `Final_` — Final project defense and comprehensive demonstration deck
- `Diagram_` — Standalone architectural or flow diagrams

### Examples:
- `Proposal_MultimodalStressAssessment_20260215.pdf`
- `Milestone1_Architecture_and_Voice_Pipeline_20260310.pptx`
- `Diagram_System_Architecture_Overview.svg`
- `Diagram_Voice_Preprocessing_Pipeline.png`

## Presentation Content Guidelines

When creating presentation materials, ensure all decks adhere to the core project identity:
1. **Title Integrity:** Use the official project title: `Emotion Aware Cloud Platform For Mental Health Monitoring Using Multimodal AI`.
2. **Three-Modality Scope:** Emphasize the three complementary modalities (Questionnaire, Voice, Behavioral) and note that video, facial analysis, and wearable sensors are explicitly excluded.
3. **Non-Clinical Framing:** Maintain strictly non-clinical language ("stress/risk indicators", "estimated risk", "supportive recommendations"); never state that the system diagnoses clinical mental illnesses.
4. **Member Contributions:** Attribute modality progress clearly according to confirmed team ownership (Khwaish: Questionnaire, Nandini: Voice, Netal: Behavioral & Fusion).
